# 演示步骤

约 5 分钟。云端在本机，断网用页面开关模拟，要如实告诉评委。

## 开场前

用发布包时，双击 `启动演示-回放.bat` 就是回放备份，它会清掉上一次的演示记录，并启动手机和云端，可以跳过下面第 1 到 4 条。

1. 关掉之前开着的手机和云端程序。
2. 删掉上一次的数据：`演示\phone.db`、`演示\cloud.db`。
3. 决定用哪种云端，只开一个：

现场调用星火（要联网，第一轮新题约 1 到 3 分钟才到）：

```
.venv\Scripts\python.exe -m xiangke.cloud --db 演示\cloud.db
```

回放备份（不联网，马上有结果，页面会标明“提前写好”）：

```
.venv\Scripts\python.exe -m xiangke.cloud --db 演示\cloud.db --replay 演示\星火录制.json
```

4. 另开一个终端启动手机：

```
.venv\Scripts\python.exe -m xiangke.app --db 演示\phone.db
```

5. 打开两个页面：手机 `http://127.0.0.1:8765`，老师和家长 `http://127.0.0.1:8766`。

## 第一轮：断网做错题

确认右上角是“已断网”。

**第 1 道。** 点“拍一道题”，选 `演示\题目.png`，点 `She ___ apples. (like / likes)`，点“是这道题”。

| 孩子打字 | 手机 |
|---|---|
| 一个 | 答对了，问选哪个 |
| like | 还不对，再想想 |
| likes | 答对了 |

**第 2 道。** 回首页，点课包里的 `改错（只改一个词）：She like cats.`，点“是这道题”。

| 孩子打字 | 手机 |
|---|---|
| cats | 还不对，再想想 |
| like | 答对了，问主语 |
| 一个 | 答对了，问改成什么 |
| like | 还不对，再想想 |
| 为什么要加s | 讲规则，不算答错 |
| likes | 答对了 |

**第 3 道。** 回首页，拍题图或输入 `They ___ my friends. (am / is / are)`，依次打 `They`、`are`，全对。

## 第二轮：联网，云端老师工作

1. 点右上角切到“已联网”，点“同步”。
2. 错过的两道题马上回到手机。讲法更新到第 3 版，专属题也到了。现场调用星火时要等，页面会自动接收。
3. 切到反馈页，看“给家长”和“给老师”。讲清楚：次数和今晚怎么做是程序写的，卡在哪是星火写的。

## 第三轮：再断网，按新讲法讲

1. 手机切回“已断网”。
2. 点专属题 `She ___ apples. (like / likes)`。讲法从两问变成三问，多了“动词要变吗”。这是小模型按新讲法现场写的。
3. 其余专属题依次做对。`She ___ English.` 开头会有“上次动词忘了变，这次留心”。
4. 按手机问的答：主语问 `一个`，要不要变问 `要`，最后答 `likes`。改错题先答 `like`，再答 `一个`，最后答 `likes`。

## 第四轮：看到进步

1. 切到“已联网”，点“同步”，讲法更新到第 4 版。
2. 回反馈页。程序的数字变了，老师的话变成“先观察”。

## 要注意

- **回放只认这套操作。** 做错和做对的题要和上面一样，否则不回放新讲法和星火的话，只有程序的数字和错过的原题。这是故意的，免得显示对不上的话。
- **第 2 道的问题要用“为什么要加s”。** 手机现在只会回一句固定规则，问别的可能答不到点上。
- **这些问答是真模型在回放模式下核对过的。** 小模型现场写，同样的讲法一般写出同样的话。换了模型或讲法要重新走一遍。
- **这份录制的题偏窄**，几乎都是 `She` 和 `likes`，因为是挑内容最准的一份。
- **重新录制：** 云端加 `--record 演示\星火录制.json`，按上面操作走一遍，读完再用。
