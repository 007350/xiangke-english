# 演示步骤

约 5 分钟，加上第三轮的新题约 7 分钟。云端在本机，断网用页面开关模拟，要如实告诉评委。

## 开场前

平时体验使用实时星火。保留现有数据库，用原来指定的 `--db` 路径重新启动。下面用 `演示\cloud.db` 和 `演示\phone.db` 举例。实时答疑要联网，第一轮新题约 1 到 3 分钟才到。

```
.venv\Scripts\python.exe -m xiangke.cloud --db 演示\cloud.db
```

另开一个终端启动手机。

```
.venv\Scripts\python.exe -m xiangke.app --db 演示\phone.db
```

打开手机页 `http://127.0.0.1:8765` 和学情反馈页 `http://127.0.0.1:8766`。需要复查旧录制时，可以用 `启动演示-回放.bat`，脚本会另外创建临时数据库。

## 第一轮：断网做错题

确认右上角是“已断网”。

**第 1 道。** 点“拍一道题”，选 `演示\题目.png`，点 `She ___ apples. (like / likes)`，点“是这道题”。

| 孩子打字 | 手机 |
|---|---|
| 一个 | 答对了，问选哪个 |
| like | 提示怎么找线索，再试一次 |
| likes | 根据提示改对了 |

**第 2 道。** 回首页，点课包里的 `改错（只改一个词）：She like cats.`，点“是这道题”。

| 孩子打字 | 手机 |
|---|---|
| cats | 提示先找表示动作的词 |
| like | 根据提示改对了，接着问主语 |
| 一个 | 答对了，问改成什么 |
| like | 提示怎么判断动词要不要变形 |
| 为什么要加s | 讲规则，不算答错 |
| likes | 答对了 |

**第 3 道。** 回首页，拍题图或输入 `They ___ my friends. (am / is / are)`，依次打 `They`、`are`，全对。

## 第二轮：联网，云端老师工作

1. 点右上角切到“已联网”，点“同步”。
2. 错过的两道题马上回到手机。讲法更新到第 3 版，专属题也到了。现场调用星火时要等，页面会自动接收。
3. 切到反馈页，看“给家长”和“给老师”。讲清楚：次数和今晚怎么做是程序写的，卡在哪是星火写的。

## 第三轮：读完回信，试一道新题

1. 手机上点「老师的回信」，读完「为什么要加s」的回信，点「读完回信，试一道新题」。
2. 新演示库里，第一题通常是 `He ___ TV. (watch / watches)`。直接选 `watches`，看孩子能不能把规则用到没见过的题上。
3. 回到同一封回信再点一次，第二题通常是 `She can ___ TV. (watch / watches)`。有 can 帮忙就不变，选 `watch`。每天最多两道。如果以前做过候选题，会换一道。跨日再点同一封回信，继续测原考点并自动换题。
4. 切「已联网」点「同步」。到「给老师」页看「读完回信试的新题」卡。这里会显示回信原题、考点，以及独立做对、提示后改对或停下来的结果。跨日做的题会标「跨日复测」。
5. **老师确认闭环**：同在「给老师」页，「疑惑与云端解答」里可以直接改一句解释，点「确认并发回」。回手机点「同步」，再打开回信，这条会标「老师确认过」。这一步不调大模型，回放模式下也能现场演示。
6. 点「复制给老师」，文本里有这两道新题的记录，末尾注明演示备份来源。如果浏览器拦截自动复制，页面会展开并全选反馈全文，可以按 Ctrl+C 或用手机选择菜单复制。

回信后的验收题直接让孩子选词，孩子求助或作答后才有讲解。普通辅导仍由小模型现场组织小问。

## 第四轮：再断网，按新讲法讲

1. 手机切回“已断网”。
2. 点专属题 `She ___ apples. (like / likes)`。讲法从两问变成三问，多了“动词要变吗”。这是小模型按新讲法现场写的。
3. 其余专属题依次做对。`She ___ English.` 开头会有“上次动词忘了变，这次留心”。
4. 按手机问的答：主语问 `一个`，要不要变问 `要`，最后答 `likes`。改错题先答 `like`，再答 `一个`，最后答 `likes`。

## 第五轮：看到进步

1. 切到“已联网”，点“同步”，讲法更新到第 4 版。
2. 回反馈页。程序的数字变了，老师的话变成“先观察”。

## 要注意

- **回放只认这套操作。** 做错和做对的题要和上面一样，否则不回放新讲法和星火的话，只有程序的数字和错过的原题。这是故意的，免得显示对不上的话。第三轮的两道新题和老师的确认不影响对号，随时可以加演。
- 实时答疑会处理孩子留下的实际疑惑。用旧录制复查第 2 道题时，匹配的原话是“为什么要加s”。其他提问仍保留在待答疑队列。
- **这些问答是真模型在回放模式下核对过的。** 小模型现场写，同样的讲法一般写出同样的话。换了模型或讲法要重新走一遍。
- **这份录制的题偏窄**，几乎都是 `She` 和 `likes`，因为是挑内容最准的一份。
- **重新录制：** 云端加 `--record 演示\星火录制.json`，按上面操作走一遍，读完再用。
