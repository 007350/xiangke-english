# 乡课英语：断网也能用的小学英语辅导

乡村孩子晚上做英语作业，家里常常没有人能听出 `I am` 和 `I is` 的区别。这个项目让孩子拍下一道题，在**断网**的情况下，由本地小模型一步步带着做，程序负责判对错。

联网之后，云端的星火大模型读这个孩子的记录，更新讲法和档案，给家长和老师写反馈，再发几道专属错题。下次断网时，小模型就按新讲法讲。

这个包在电脑上用网页代替手机，云端也在同一台电脑上，用页面开关模拟断网。**还不是真手机 App，也还不是真云端服务器。**

演示录屏是单独的视频文件，没有放进这个压缩包。

## 分工：程序给答案，模型来讲

手机上的星火小模型参数量只有 1.7B，会讲错，所以不让它决定对错。

| 环节 | 谁来做 |
|---|---|
| 认题（OCR）、孩子确认题目 | 本地 OCR + 孩子 |
| 算答案 | 程序。算不准就拒绝，不猜 |
| 把题拆成几问、讲解 | **小模型**（最后一问的答案锁成程序算的） |
| 听懂孩子的话（答题、不会、提问、闲聊） | **小模型** |
| 判对错、记录 | 程序 |
| 程序算不出的题 | **小模型试做**，告诉孩子不一定对，不判对错 |

小模型讲的内容要先过程序检查，不合格就换成程序写好的说法。

云端按程序定好的步骤走，每一步的判断交给星火大模型（默认 `spark-x2.6`）：

| 环节 | 谁来做 |
|---|---|
| 档案：做过几次、错过几次 | 程序 |
| 档案：卡在哪、接下来练什么 | **星火大模型** |
| 下一版讲法 | **星火大模型**，程序检查 |
| 错过的原题发回手机 | 程序，答案也由程序算 |
| 新的专属题和答案 | **星火大模型**出题，程序把关，星火看不到答案再做一遍，对不上就不发 |
| 反馈里的次数、要不要老师出手、今晚怎么做 | 程序 |
| 反馈里孩子卡在哪、老师要不要讲 | **星火大模型**，逐句检查，不合格换程序的说法 |

星火写的内容不稳定：我们见过乱码、错答案、语法不通的题，也见过只错一次就下结论的话。所以这些检查不能撤。检查也拦不住所有不好的话，真实效果还要人读。

## 微调过程

**基座模型：** `XHToken/Spark-X2.5-1.7B`（星火 1.7B），用 LoRA 微调，基座不变。

### 任务和数据格式

模型学的任务是：输入一道孩子确认过的题，以及这个孩子的讲法、易错提醒和拆题样例；输出一个 JSON，把题拆成 2～3 问，每问有问句 `ask`、答案 `expect` 和解释 `explain`。所有样本用同一份系统提示词。

```json
{"steps": [
  {"ask": "空格前面紧挨着的那个英文词是什么？", "expect": "can", "explain": "空格前面紧挨着的是 can。"},
  {"ask": "can 后面的动词要不要变形？说「要」或「不要」。", "expect": "不要", "explain": "can 后面的动词总是用原来的样子，不管主语是谁，都不加 s。"},
  {"ask": "那空里选 swim 还是 swims？", "expect": "swim", "explain": "can 后面的动词总是用原来的样子，所以填 swim。"}
]}
```

### 训练配置

| 项目 | 取值 |
|---|---|
| 方法 | LoRA，`r=16`，`alpha=32`，`dropout=0.05` |
| 目标模块 | `q_k_v_proj`、`out_proj`、`gate_proj`、`up_proj`、`down_proj` |
| 可训练参数 | 15,826,944，占全部参数的 0.92% |
| 优化器 | AdamW，学习率 `2e-4`，余弦衰减 |
| 批量 | 每次 1 条，累积 16 条更新一次 |
| 轮数 | 3 轮，共 1232 次更新 |
| 训练精度 | bf16 |
| 硬件 | ModelScope PAI-DSW，NVIDIA A10 24GB，显存峰值 12.75 GB |
| 用时（v5） | 99 分钟 |
| 软件 | transformers 4.57.1、peft 0.17.1、torch 2.13.0 |
| 数据增强 | 约 35% 带样例的数据去掉样例里的解释（v5 为 1771 条） |

训练脚本是 `训练/v5/job/train_v5_ms.py`，支持断点续跑，并定时把结果同步回仓库。

### 一轮一轮怎么改的

**v4：只练拆题。** 5123 条数据。模型说明里的成绩很高（留出题最后答案正确约 99%），但我们用训练之外的难题去考，发现了问题：

| v4 暴露的问题 | 查 `train.jsonl` 后的原因 |
|---|---|
| 把 `She`、`We` 说成“我” | 没有标错，是例子不平衡：“主语是哪一种”这个问法，`I` 有 44 条，`She` 只有 2 条 |
| `can swims`、`I has`、`don't`、`was` 不会改 | 这些改错题 0 条 |
| `She can ___` 选错 | `can` 后面直接是空的 0 条 |
| 解释里说“第三人称单数”，孩子听不懂 | 430 条数据里有这个词 |
| 编理由，如“句子里还有 cats，所以……” | 185 条有“句子里还有 now 表示现在”，模型学成了乱找理由（这条在 v6 数据里才清理） |

**这也是这个项目最重要的一条经验：** 模型错了先查数据，不要直接加数据。如果只凭感觉微调，这些错误来源是看不出来的。

**v5：针对错误补数据。** 从基座重新训练，共 6573 条：

| 数据 | 条数 |
|---|---|
| 旧数据（题和答案不变，改掉解释里的“第三人称单数”，涉及 430 条答案） | 5123 |
| 代词主语平衡 | 300 |
| `can`、`to`、`does` 后面用原形，以及动物主语 | 250 |
| 改错缺口：`I has`、`don't`、`was`、`There` | 300 |
| 拼写的中间字母（带双字母的词） | 100 |
| 听懂孩子的话（答题 150、不会 110、提问 140、其他 100，单独的提示词） | 500 |

新数据由程序生成，另有一个独立的检查程序核对答案、格式，并确认它和测试题互不混入（`训练/v5/build_ds.py`、`check_ds.py`）。

**v6：练“照着答案讲”（数据已备好，还没训练）。** 七成数据在题目后面加一行程序算出的答案，并清理“句子里还有 now”。

### 训练过程的数据（v5）

| 轮次 | 留出题损失 |
|---|---|
| 1 | 0.3098 |
| 2 | 0.3483 |
| 3 | 0.3729 |

训练损失从第 50 步的 0.198 降到 0.0073，但**留出题损失在上升，有过拟合的迹象**。最终用了第 3 轮，因为实际验收成绩好；第 1、2 轮的模型也保存了，还没有比较。

## 量化过程

要在 CPU 上离线运行，模型必须变小。流程是（脚本 `训练/v6/export_gguf.sh`、`merge_lora.py`）：

```text
基座 + LoRA adapter
  │ 用 fp32 合并（W' = W + (alpha/r)·B·A，alpha/r = 2.0）
  ▼
合并后的权重（存成 bf16 safetensors，约 3.4 GB）
  │ llama.cpp 的 convert_hf_to_gguf.py --outtype f16
  ▼
f16 的 GGUF
  │ llama-quantize Q4_K_M
  ▼
Q4_K_M 的 GGUF（约 1.03 GB）
```

**为什么这样做：**
- **先用 fp32 合并：** 合并时的数值误差更小，再转成 bf16 保存。
- **选 Q4_K_M：** 这是体积和质量之间常用的平衡，模型缩小到约三分之一，可以在普通电脑的 CPU 上跑。
- **从合并后的模型转换：** 不用在运行时单独加载 LoRA，部署只有一个文件。

| 结果 | v4 | v5 |
|---|---|---|
| 文件大小 | 1,107,457,376 字节 | 1,107,457,952 字节 |
| 转换用时 | | 在 DSW 上约 10 分钟 |

v5 的 SHA256：`97239079404d0a2159f891cf34d90ab615844cb1309dfa8d0f78262af9f6b168`

**量化后的验证：**
- **v4：** 合并结果和 PEFT 官方 `merge_and_unload()` 逐张量比对，226 个权重张量完全一致；量化后 CPU 上考 20 题全部通过（数据来自 v4 的模型说明）。
- **v5：** 用的是同样的流程，但**没有重新做逐张量比对**，也没有对比量化前后的差别。下面的成绩都是直接考量化后的文件，也就是实际运行的版本。

**运行时要注意：** 必须用训练时的对话模板（`<|Bot|>` 后带 `</think>`）和贪心解码（`temperature=0`、`top_k=1`）。我们测到 llama.cpp 的通用对话接口有时结果不同，所以代码里自己拼模板（`xiangke/local_model.py`）。

## 结果

都是用训练数据之外的题，在普通电脑的 CPU 上考量化后的模型。

| 项目 | v4 | v5 |
|---|---|---|
| 60 道验收题（最后答案） | 40 | **60** |
| 其中 `can`、`to`、`does` | 2/12 | **12/12** |
| 其中改错缺口和 `There` | 6/14 | **14/14** |
| 把主语说成“我”（模型自己做） | 4 次 | **0 次** |
| 解释里带“第三人称” | 14 道 | **0 道** |
| 听懂孩子的话（60 句） | 19 | **57** |
| 程序能给答案的 28 道里，用模型讲的 | 12 | **24** |
| 判对错用的答案出错 | 0 | 0 |
| **外部 40 题** | **39** | **37（退步）** |

程序算答案：用旧数据的标准答案核对，算了 829 道，错 0 道。但这不代表程序不会错：星火出的题里，`(can / cans)` 程序就算错了，已经修好。

**云端的实测（2026-11-05，样本很小）：**

| 项目 | 结果 |
|---|---|
| 星火出题（开思考），30 道的答案 | 都对，但有题目毛病和重复 |
| 星火出题（关思考），6 道 | 2 道答案错，被程序拦下，所以现在开着思考 |
| 写讲法用时 | 关思考 9～14 秒，开思考 26～63 秒，现在关着 |
| 从同步到新题送达 | 约 1 到 3 分钟，重做核对偶尔超时，这批新题就不发 |
| 小模型按新讲法讲，同样 7 道题 | 问句变了 6 道，其中有的只改了一两个字，有的变差 |

**看这些数字时要注意：**
- **60/60 偏乐观：** 验收题和新训练数据都是我们自己写的，句式相近。唯一的外部题反而退步了，所以**真实作业上的水平还不知道**。
- **讲解对不对主要靠人读：** 程序只能拦下一部分错误。比如模型问过“空格是整个词还是部分词”，检查就没拦住。
- **还没有请老师看过讲解，也没有用真实作业和真手机测过。**
- **演示录屏和录好的星火内容是挑过的：** 录了几次，选了内容最准的一份。它代表较好的情况，不是平均水平。

## 怎么运行

这个包带了运行模型用的 llama.cpp，**目前只能在 Windows 上运行**。模型约 1.03 GB，第一次运行时自动下载。

1. 安装 Python（我们用 3.13.9，3.10 以上应该也可以，但没有测过）
2. 在这个文件夹里运行：`pip install -r requirements.txt`
3. 选一种方式启动：

| 想做什么 | 双击 | 要不要星火令牌 |
|---|---|---|
| 看完整流程（推荐） | `启动演示-回放.bat`，再照 `演示/演示步骤.md` 操作 | 不要。云端内容是提前录好的，页面会标明 |
| 只用手机端 | `启动.bat` | 不要 |
| 现场调用星火 | 先 `启动云端.bat`，再 `启动.bat` | 要 |

第一次会先下载模型，以后不用再下。用完关掉黑色窗口即可。

**现场调用星火：** 先在讯飞控制台拿到令牌，自己设到环境变量 `AI_API_KEY`，不要写进文件，也不要发给别人。地址和模型默认是 `https://maas-api.cn-huabei-1.xf-yun.com/v2` 和 `spark-x2.6`，可以用 `AI_BASE_URL`、`AI_MODEL` 改。孩子的题目和原话会发给星火，不带孩子编号和时间。

老师和家长的页面在 `http://127.0.0.1:8766`。云端现在只在本机打开，没有登录，不能直接放到公网上。

**模型地址：** <https://www.modelscope.cn/models/xiaobang123/xiangke-lora-job-v5/resolve/master/gguf/xiangke-v5-Q4_K_M.gguf>

也可以手动下载，放到 `models/v5/gguf/xiangke-v5-Q4_K_M.gguf`。下载中断后，再运行一次会接着下；下完会核对校验值。手动启动用：`python -m xiangke.app`，再打开 `http://127.0.0.1:8765`。

**用起来要注意：**
- 手机端只有安装依赖和第一次下载模型时要联网，之后可以离线。现场调用星火的云端要联网。
- 首页右上角是模拟网络的开关。云端也在这台电脑上，真断网断不开，所以用开关。
- 开始一道题要等 5～15 秒，取决于电脑的 CPU。
- 这是电脑上的网页，用来体验手机端流程。按“手机尺寸”看效果最好，比如把浏览器窗口拉窄。
- 可以先试“课包里的题”，也可以输入 `She can ___. (swim / swims)`、`改错（只改一个词）：He go to school.` 这样的题。
- 做题记录存在 `demo/phone.db`。

只跑测试不需要模型，也不调用星火：`python -m unittest discover -s tests -t .`（缺少教材照片时，有 1 项会跳过）。
