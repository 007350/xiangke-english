# 规则表

草稿，还没接进程序。一条题只用一条最具体的规则，再把这句中文交给讲解。整张表不进模型。

算不出该用哪一条，或者拼写题里没有写好的单词，这道题不讲。

## be_verb

选 `am`、`is`、`are`。主语对上越具体的那一条，就越用它。

| 编号 | 什么时候用 | 讲给孩子的话 |
|---|---|---|
| `be_i` | 主语是 I | 主语是 I，用 am。 |
| `be_you` | 主语是 you | 主语是 you，用 are。一个 you 和许多 you 都用 are。 |
| `be_we` | 主语是 we | 主语是 we，用 are。 |
| `be_they` | 主语是 they | 主语是 they，用 are。 |
| `be_he_she_it` | 主语是 he、she 或 it | 主语是 he、she、it，用 is。 |
| `be_this_that` | 主语是 this 或 that | this 和 that 用 is。 |
| `be_these_those` | 主语是 these 或 those | these 和 those 用 are。 |
| `be_singular` | 上面都不是，主语是一个 | 主语是一个，用 is。 |
| `be_plural` | 上面都不是，主语是两个或更多 | 主语是两个或更多，用 are。 |

## plural_noun

空里选单数还是复数。先看空前面的数量，不看名词自己的词尾去编变化。

| 编号 | 什么时候用 | 讲给孩子的话 |
|---|---|---|
| `n_a_an` | 空前面是 a 或 an | a 和 an 后面用一个，名词不加 s。 |
| `n_a` | 要在 a 和 an 里选，读音以辅音开头 | 辅音读音开头用 a。看读音，不看第一个字母。 |
| `n_an` | 要在 a 和 an 里选，读音以元音开头 | 元音读音开头用 an。apple 就是这种。 |
| `n_one` | 数量是 1，或空前面是 one | 数量是 1，用单数。 |
| `n_many` | 数量是 2 或更多 | 数量是 2 或更多，用复数。这一轮只收词尾加 s。child、man 这种先不放。 |

## verb_3s

改一个词：动词加不加 s。`v_she` 不是另一条选择，主语是 she 时必须和 `v_3s` 一起用，避免把 she 说成「我」。

| 编号 | 什么时候用 | 讲给孩子的话 |
|---|---|---|
| `v_base` | 主语是 I、you、we、they | 主语是 I、you、we、they，动词用原来的样子，不加 s。 |
| `v_3s` | 主语是 he、she、it，或一个 | 主语是 he、she、it，或一个，动词一般加 s。 |
| `v_she` | 主语是 she | she 是她，一个人，不是我。 |
| `v_irregular` | 动词是 go、do、have | go、do、have 要写成 goes、does、has。 |

这一轮不收以 s、x、ch、sh 结尾加 es，也不收辅音加 y 改成 ies。碰上这种词，不用 `v_3s` 硬加 s，这道题不讲。

## spelling

拼写没有口诀。缺的字母只从这道题写好的单词里数出来。题里没有这个单词，就不讲。

| 编号 | 什么时候用 | 讲给孩子的话 |
|---|---|---|
| `sp_stored` | 这道题写好了完整单词 | 不另编规则。空着的字母按这个单词填。 |

## 现在这四道题会用到哪一条

| 题目 | 用哪一条 | 程序算出的最后答案 |
|---|---|---|
| `They ___ my friends. (am / is / are)` | `be_they` | `are` |
| `This is an ___. (apple / apples)` | `n_a_an` | `apple` |
| `改错（只改一个词）：She like cats.` | `v_she` 和 `v_3s` | `likes` |
| `看中文写单词：书 b__k` | 没有写好的单词，`sp_stored` 用不上 | 不讲 |
