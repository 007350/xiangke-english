# 课包格式

老师填一份 Excel，程序按固定的表名和列名读取。空白模板是 `data/课包模板.xlsx`，填好的样例是 `data/课包样例.xlsx`。

`data/pack.json` 不是这个格式。它仍然只是回路测试用的四句题目原文。

现在只定了格式，读取程序、老师确认页面和上传功能都还没有做。

## 五张数据表

另有一张「填写说明」是给老师看的，程序不读。每张数据表第一行是表头，从第二行开始是内容，整行空白的跳过。表名和表头不能改。

### 课包信息

| 项目 | 内容 | 要求 |
|---|---|---|
| 课包编号 | 例如 `pack_demo_01` | 必填，只用英文字母、数字和下划线 |
| 课包版本 | 例如 `1` | 必填，从 1 开始的整数，每次更新加 1 |
| 年级 | 例如 `三年级` | 必填 |
| 单元 | 例如 `第一单元` | 必填 |

### 单词

| 列 | 要求 |
|---|---|
| 中文 | 必填 |
| 英文 | 必填，一个完整的英文单词 |
| 词性 | 必填，只能选 `动词`、`名词`、`形容词`、`其他` |

### 题目

| 列 | 要求 |
|---|---|
| 题号 | 必填，同一个课包里不能重复 |
| 题型 | 必填，只能选 `选词`、`填空`、`改一个词`、`单词拼写` |
| 题目原文 | 必填，空写成 `___`，选项写成 `(am / is / are)`，拼写题缺的字母写成 `_` |
| 标准答案 | 必填，填进空里的词、改正后的词，或完整的单词 |

### 本单元规则

规则编号和规则名称已经写好，不能改。老师只把「这单元教吗」选成 `是` 或 `否`。

| 规则编号 | 规则名称 | 例子 |
|---|---|---|
| `be_verb` | 选 am / is / are | `They ___ my friends.` → `are` |
| `plural_noun` | 选单数或复数 | `This is an ___.` → `apple` |
| `v_3s` | 动词直接加 s | `She like cats.` → `likes` |
| `v_es` | 动词加 es | `She watch TV.` → `watches` |
| `v_ies` | 辅音字母加 y，改成 ies | `He study English.` → `studies` |
| `v_irregular` | go、do、have 的特殊变化 | `He go to school.` → `goes` |
| `spelling` | 单词拼写 | `书 b__k` → `book` |

`v_es`、`v_ies`、`v_irregular` 也在这一轮要讲的范围内。程序暂不支持的规则，老师选了 `是`，要明确提示暂不支持，不能当作已经能教。

### 老师讲法

选填。同一条规则可以写多行。讲法只交给模型参考，不影响对错。

| 列 | 要求 |
|---|---|
| 规则名称 | 从「本单元规则」的规则名称里选 |
| 讲法 | 老师常用的一句话 |

## 读取后的结果

```json
{
  "packId": "pack_demo_01",
  "packVersion": 1,
  "grade": "三年级",
  "unit": "样例单元",
  "words": [
    {"zh": "书", "en": "book", "pos": "noun"}
  ],
  "items": [
    {"itemId": "1", "kind": "choose", "recognizedText": "They ___ my friends. (am / is / are)", "answer": "are"}
  ],
  "rules": ["be_verb"],
  "teacherWords": [
    {"ruleId": "be_verb", "text": "主语是 they，用 are。"}
  ]
}
```

`rules` 只放选了 `是` 的规则编号。

| 表格里的词 | 结果里的值 |
|---|---|
| 动词、名词、形容词、其他 | `verb`、`noun`、`adj`、`other` |
| 选词、填空、改一个词、单词拼写 | `choose`、`fill`、`fix`、`spell` |

## 读取时必须拒绝的情况

有下面任何一种情况，整份课包都不进手机，并告诉老师是哪张表、第几行、错在哪里：

- 少了某张表或某一列。
- 必填的内容是空的。
- 课包版本不是从 1 开始的整数。
- 题号重复。
- 词性、题型、这单元教吗不是规定的选项。
- 英文单词里有字母以外的内容。
- 规则编号或规则名称被改过。
- 老师讲法里的规则名称不在「本单元规则」里。

通过这些检查后，也要先把内容显示给老师确认，确认后才生效。老师的答案和程序算的不一样时，提醒老师核对，程序不自己选。
